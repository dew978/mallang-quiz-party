# 말랑 퀴즈 파티

초등 1~6학년 복습용 3D 파티 게임. 하늘 위 젤리 섬 퀴즈 쇼에 말랑이 12명이 참가해, 장애물 코스를 달리고 뛰고
몸을 날리며 **정답을 몸으로 고르는** 라운드 4개를 겨룬다. 브라우저(three.js)에서 설치·가입 없이 돌아가고,
태블릿 가로 화면을 기준으로 만들었다. **삼대710 제작**

- **플레이: https://dew978.github.io/mallang-quiz-party/**
- 기획서: [기획서.md](기획서.md) · 제작 과정: [docs/제작과정.md](docs/제작과정.md) · 이어서 작업하기: [docs/이어서-작업하기.md](docs/이어서-작업하기.md)

## 실행
main 브랜치가 GitHub Pages로 그대로 배포된다(빌드 없음). 내 컴퓨터에서는 이 폴더를 아무 정적 서버로 연다 (예: `npx http-server -p 8130 -c-1` 뒤 http://localhost:8130).
파일을 더블클릭해서 열면 모듈·모델을 못 불러오므로 꼭 서버로 연다. 친구와 파티는 인터넷이 필요하다(PeerJS 중개 서버).

- `?play=doors` / `tiles` / `balloons` / `tower` — 그 라운드 바로 시작 (`&demo`를 붙이면 내 말랑이도 스스로 움직임)
- `?room=ABCDE` — 초대 링크: 그 방으로 바로 들어감

## 흐름
타이틀(시작하기 / 설정, 전체화면) → 학년 → 학기 → 과목 → 메뉴(혼자 파티 · 친구와 파티 · 꾸미기 상점 · 공부 기록, 위에 과목 칩·코인·설정)
→ 혼자 파티: 모드 고르기(파티 쇼 / 라운드 하나 연습, 봇 실력) → 캐릭터 고르기 → 라운드(소개 카드 → 3·2·1 → 경기 → 끝!) → 중간 순위 → … → 결과(시상대, 별·코인, 이번에 틀린 문제, 다시 하기 / 처음으로)
경기 중 왼쪽 위 ⏸: 계속하기 · 설정 · 처음으로. 오른쪽 위 ⛶ 전체화면은 언제나.

## 라운드
| 라운드 | 하는 일 | 문제 | 별 |
|---|---|---|---|
| ① 정답 문 대시 | 통통 기둥 → 회전 막대 2개 → 구름 징검다리 → 흔들 사탕 추를 지나 벽마다 정답 문으로 돌진. 틀린 문은 띠용~ 튕기고 ✕ 표시 | 벽 4개 | 첫 시도 정답 +2(부스터), 도착 1~3등 +3/+2/+1 |
| ② 젤리 발판 서바이벌 | 둥근 섬이 보기 색 구역으로 나뉨. 시간이 끝나면 틀린 구역이 흔들리다 떨어짐. 4번째부터 회전 막대, 6번째부터 섬이 돎. 떨어지면 하늘에서 다시 내려옴 | 8개 | 버티면 +1 (마지막 2문제 +2) |
| ③ 정답 풍선 사냥 | 보기 글자가 적힌 풍선을 몸으로 터뜨림. 한 문제에 하나만. 높은 풍선은 귀퉁이 트램펄린으로 | 6개 | 정답 1등 +3, 2등 +2, 그 뒤 +1. 오답은 먹물+어지러움 |
| ④ 결승: 왕관 구름 계단 | 층마다 보기 점프대. 정답이면 위층으로 슈퍼 점프, 오답이면 바람 빠지며 튕김. 꼭대기 왕관 | 4개 | 첫 시도 정답 +2, 왕관 +5, 꼭대기 2·3등 +3/+2 |

파티 쇼는 ①②③ 순서를 섞고 마지막은 ④. 문제는 위쪽 카드에 크게(굵지 않은 글꼴), 보기는 색+모양(●▲■★)으로 표시하고 번호는 쓰지 않는다.
정답이 정해지면 "정답 풀이" 띠가 2~3초 나온다(게임은 멈추지 않음). 틀린 문제는 오답 노트에 쌓이고 다음 파티에 다시 나온다.
제한 시간은 학년(1~2학년 12초, 3~4학년 10초, 5~6학년 8.5초) + 글 길이, 설정에서 넉넉하게/보통/빠르게.
1~2학년은 문제와 보기를 소리로 읽어 준다(설정: 1~2학년만 / 켜기 / 끄기, 브라우저 한국어 음성).

## 조작
| 동작 | 키보드 | 태블릿 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽을 눌러 끌기 (떠다니는 조이스틱) |
| 점프 | Space | 오른쪽 아래 점프 단추 |
| 다이브(몸 날리기) | Shift / E | 점프 옆 다이브 단추 |
| 멈춤 | Esc | ⏸ |
카메라는 자동(화면 위쪽 = 앞). 코요테 타임·미리 누르기로 "눌렀는데 안 뛰었다"가 없게 했다. 말랑이끼리 부딪히면 튕기고, 다이브로 부딪히면 넘어뜨린다. 머리를 밟으면 통통 튄다.

## 친구와 파티 (멀티)
방장이 **새 방 만들기** → 영문 5글자 코드·초대 링크·QR → 친구가 코드를 넣거나 링크를 열면 들어옴(최대 8명, 빈자리는 봇).
방장이 모드(파티 쇼 / 라운드 하나)를 고르고 **모두 출발!**. 방장의 학년·과목 문제로 모두 함께 풀고, 친구의 기록도 그 과목으로 남는다.
호박 저택 탈출과 같은 PeerJS(WebRTC) 방식이라 서버가 필요 없다: 각자 자기 말랑이를 움직여 1초에 15번 위치를 보내고, 방장이 봇·라운드 끝을 정한다.
라운드는 모두 불러온 뒤(최대 8초 기다림) 함께 시작한다. 풍선은 같은 씨앗으로 모든 기기에 같은 자리에 뜨고, 터뜨림·왕관은 모두에게 알린다.
같은 이름으로 다시 들어오면 원래 자리로 돌아간다(대기실에서). 기기끼리 직접 이어지지 않는 와이파이(기기 간 차단)에서는 연결이 안 된다.

## 상점·기록
- 캐릭터 6종: 모찌(토끼)·보리(곰)·삐약(병아리) 기본, 치즈(고양이)·디노(공룡)·팡이(판다) 400코인
- 모자 9종(꽃 핀·리본·야구 모자·헤드셋·고글·유니콘 뿔·마법사 모자·헬멧·왕관, 정수리 자동 맞춤), 발자국 효과 4종(별·하트·음표·무지개)
- **사려면 문제를 맞혀야** 한다(틀리면 코인은 그대로, 다른 문제로 다시). 카드 그림은 게임 속 모델을 그대로 찍은 것.
- 공부 기록: 과목별 정답률, 오답 노트(다시 풀기, 두 번 연속 맞히면 졸업), 파티·우승·왕관 수
- 코인 = 별 × 5 + 주운 동전 + 순위 보너스(+왕관 30)

## 문제은행
1~6학년 × 1·2학기 × 과목(1~2학년 국어·수학·통합, 3~6학년 국어·수학·사회·과학·영어). 2022 개정 교육과정 기준.
Q-레이서 문제은행 4,778문항 + 이번에 새로 만든 1~3학년 905문항(`questions_extra_e.js`)·4~6학년 960문항(`questions_extra_f.js`), 수학은 단원 생성기(74단원)로 매번 새 문제.
한 묶음(학년·학기·과목)마다 110~170문항이고, 최근에 낸 문제는 은행을 거의 다 돌 때까지 다시 내지 않는다(기기에 저장).

## 만든 것·도구
- 3D: 캐릭터 6종·장식 9종·왕관 — 로컬 ComfyUI(FLUX.2 Klein)로 원화 → TRELLIS로 GLB (`assets/ASSET_LOG.md`). 모자 9종은 Q-레이서 모델을 다시 씀.
  말랑이 몸통은 동그란 모델 하나이고, 손·발은 코드로 붙여 달리기·점프·다이브·넘어짐·어지러움·기쁨 동작을 절차적으로 만든다(뼈대 없음).
- 무대·장애물: 코드(둥근 상자, 줄무늬·물방울 텍스처, 젤리 바다 셰이더, 구름 스프라이트). 모드 카드 사진은 게임 엔진으로 찍음.
- 소리: 효과음 34개·배경음 6곡 — 로컬 Stable Audio 3 Medium + ffmpeg (`assets/AUDIO_LOG.md`). 파일이 없으면 합성음으로 대신.
- 물리: 직접 만든 가벼운 캐릭터 물리(상자·원기둥·부채꼴 발판, 움직이는 발판, 튕김). 저사양 태블릿에서도 12명이 돈다.
- 그래픽 "가볍게"(터치 기기 기본): 그림자·안티에일리어싱 끄고 해상도 1배, 느리면 자동으로 해상도를 더 낮춤. 말랑이 발밑 그림자 원은 늘 보임(점프 착지 지점).

## 점검한 것
- 봇 자동 플레이(`&demo`)로 4라운드 각각 끝까지 진행, 파티 쇼 전체(22문제 → 중간 순위 3번 → 결과) 진행
- 낙하 위치 기록으로 고친 것: 난간을 뚫고 밀려나던 문제(난간 충돌판을 바깥쪽으로 두껍게), 빠른 착지를 옆벽으로 잘못 보던 물리 버그, 움직이는 발판 구간이 너무 어려워 고정 징검다리로 바꿈, 슈퍼 점프가 착지 판정에 덮이던 문제
- 두 탭 멀티: 초대 링크로 입장, 같은 문제·같은 풍선 자리, 풍선 터뜨림·별 동기화, 방장이 끝을 정하고 양쪽 결과 화면까지
- 1280×800, 1024×768(터치 단추)에서 HUD 겹침 확인

## 아쉬운 점
- 효과음·배경음은 길이·크기만 자동 점검했고 귀로 하나하나 들어 보지 못했다.
- 멀티는 기기마다 라운드 시간을 따로 재서, 불러오는 속도가 많이 다르면 발판이 떨어지는 순간이 기기마다 조금 다를 수 있다(정답 판정은 각자 자기 화면 기준).
- 경기 중에 끊긴 친구는 그 라운드에 다시 들어오지 못하고, 결과 뒤 대기실에서 다시 들어와야 한다.
- 캐릭터 모델: 모찌 귀 안쪽 색이 조금 칙칙하고, 막대사탕·바람개비 막대가 회색으로 나왔다.
