# 이어서 작업하기

다른 컴퓨터나 새 Claude Code 세션에서 이 게임을 이어 고칠 때 읽는 문서. 새 세션에는 먼저 이렇게 말하면 된다:

> `docs/이어서-작업하기.md`와 `README.md`를 읽고 지금 구조를 이해한 뒤, (고칠 것)을 고쳐 줘.

## 1. 받아서 실행하기
```bash
git clone https://github.com/dew978/mallang-quiz-party.git
cd mallang-quiz-party
npx http-server -p 8130 -c-1
```
http://localhost:8130 을 연다. 설치할 패키지는 없다(three.js 0.170과 PeerJS는 `vendor/`에 들어 있음). 파일을 더블클릭해 열면 안 된다(모듈·모델을 못 불러옴).
main 브랜치에 올리면 GitHub Pages가 몇 분 뒤 https://dew978.github.io/mallang-quiz-party/ 에 그대로 반영된다(빌드 과정 없음). 올린 뒤 태블릿에서는 새로고침해야 새 버전이 뜬다.

## 2. 빨리 확인하는 방법
- `?play=doors` · `tiles` · `balloons` · `tower` — 메뉴를 거치지 않고 그 라운드 바로 시작
- `&demo` — 내 말랑이도 봇처럼 스스로 움직임 (끝까지 돌아가는지 볼 때)
- 브라우저 콘솔에서 `__app.step(초)` — 화면을 그리지 않고 시간을 빨리 돌림(창이 숨겨져 있어도). `__app.session()`으로 지금 판 상태(phase, players, round)를 본다.
- 예: 라운드가 끝까지 도는지
  ```js
  // ?play=tiles&demo 에서
  let n = 0; while (__app.session() && n < 300) { __app.step(1); n++; } n
  ```
- `__app.shots()` — 라운드 무대 사진(`assets/images/round_*.jpg`)을 다시 찍는다. 단, 저장하려면 `PUT /__save?name=` 을 받아 주는 개발 서버가 필요하다(보통 정적 서버에서는 저장 안 됨).
- 저장 데이터는 localStorage `mallang_party_save_v1`. 지우려면 설정 → 기록 지우기.

## 3. 무엇을 어디서 고치나
| 고치고 싶은 것 | 파일 |
|---|---|
| 문제 추가·수정 | `js/data/questions*.js` (형식 `{q, c:[3~4개, 8자 이내], a: 정답 번호, e: 해설}`), 수학은 `js/data/mathgen.js` |
| 문제 시간·출제 방식·오답 노트 | `js/quiz.js` (`answerTime`, `nextQuestion`, `recordAnswer`) |
| 라운드별 문제 수·순서 | `js/game/party.js` (`Q_PER_ROUND`, `roundOrder`) |
| 라운드 규칙·무대·장애물 배치·봇 | `js/rounds/doors.js` · `tiles.js` · `balloons.js` · `tower.js` |
| 장애물 모양·세기(회전 막대, 흔들 추, 통통 기둥, 움직이는 발판, 동전) | `js/rounds/common.js` |
| 발판·난간·결승 아치·하늘 배경 | `js/rounds/stage.js` |
| 달리기 속도·점프 높이·다이브·부딪힘 | `js/engine/physics.js` 맨 위 `P` |
| 카메라 위치(라운드별) | 각 라운드의 `camera(b)`, 따라가는 부드러움은 `js/game/session.js` `updateCamera` |
| 카메라를 가리는 물체 숨기기 | `js/engine/occlusion.js` (맨 위 숫자들). 숨기면 안 되는 것(피할 장애물·목표물)은 `userData.camKeep = true` |
| 캐릭터 동작·손발·모자 위치·이름표 | `js/engine/mallang.js` |
| 캐릭터·모자·발자국·가격·봇 이름·봇 실력 | `js/data/game.js` |
| 별·코인 보상 | 각 라운드의 `s.award(...)`, 파티 끝 보상은 `js/game/party.js` `finish` |
| 문제 카드·배너·카운트다운 | `js/game/hud.js` + `style.css`의 `.hq`, `.banner` |
| 화면(타이틀·메뉴·상점·기록·결과) | `index.html`, `style.css`, `js/main.js` |
| 멀티(대기실·주고받는 메시지) | `js/net/lobby.js` (연결 자체는 `js/net/net.js`) |

## 4. 지켜야 할 약속 (지난 피드백)
- 보기는 색+모양(●▲■★)으로만, 번호(1. 2. 3.) 금지. 보기 글은 8자 이내 권장(넘으면 자동으로 두 줄·작게).
- 문제 글은 굵지 않은 `Gowun Dodum`. 로고·버튼은 `Jua`, 숫자는 `Lilita One`.
- 버튼은 입체(아랫면 그림자, 눌리면 내려감). 눌러도 아이콘 크기가 변하지 않게.
- 3지선다 문제 창은 정사각형 칸 3개, 4지선다는 2×2.
- 겹치는 창 없게: 문제 카드는 위 가운데, 라운드 이름은 왼쪽 위 세로, 별은 오른쪽 위, 조작 단추는 아래.
- 타이틀: 로고 가운데, 그 아래 가운데 시작하기·설정 위아래, 오른쪽 위 전체화면, 오른쪽 아래 "삼대710 제작".
- 탈락 없음: 떨어져도 다시 올라와서 모든 문제를 푼다.

## 5. 3D 에셋을 다시 만들 때
`assets/ASSET_LOG.md`에 프롬프트·씨앗·고친 점이 다 있다. 요약:
1. ComfyUI(FLUX.2 Klein 4B)와 TRELLIS는 GPU를 같이 못 쓴다. 하나 끄고 다른 하나를 켠다.
2. 캐릭터 원화는 흰 배경, 정면, **팔다리 없는 동그란 몸**(손발은 코드가 붙임), 동공·하이라이트 있는 눈.
3. TRELLIS: `C:\Users\ndh10\Downloads\Trellis\code\venv\Scripts\python.exe .\gradio_main.py --precision half` (cwd `code`, `PYTHONNOUSERSITE=1`). 텍스처 캐릭터 1024 / 소품 512.
4. 모델 약속: Y가 위, 앞이 +Z, 크기 약 1. 결과는 `assets/models/이름.glb`, `assets/models/manifest.json`에 이름 추가.
5. 원화(`assets/images/char_*.png`, `src_*.png`)는 다시 만들 때 쓰려고 남겨 둔 것이고 게임에서는 쓰지 않는다.
모델 파일이 없으면 코드로 만든 간단한 모델로 대신하므로 게임은 계속 돈다.

## 6. 알려진 문제와 다음에 할 만한 것
- 효과음·배경음을 귀로 들어 보지 못했다 → 실제로 켜서 거슬리는 소리 바꾸기 (`assets/audio/`, `js/audio.js`의 `GAIN`).
- 실제 태블릿·교실 와이파이에서 멀티 시험 필요. 기기 간 직접 연결이 막힌 망에서는 안 된다(호박 저택 탈출과 같음).
- 멀티에서 경기 중 끊긴 친구는 그 라운드에 못 돌아온다(결과 뒤 대기실에서 다시 들어옴).
- 멀티 라운드 시간은 기기마다 따로 잰다(시작은 맞춰 줌). 발판이 떨어지는 순간이 기기마다 아주 조금 다를 수 있다.
- 모델 흠: 모찌 귀 안쪽 색, 막대사탕·바람개비 막대가 회색.
- 해 볼 만한 것: 선생님용 문제 직접 넣기(JSON 붙여넣기, 호박 저택 탈출처럼), 라운드 더 만들기(예: 정답 컨베이어, 정답 꼬리잡기), 학급 랭킹.
